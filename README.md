<center><p style="text-align: center;">This mod fixes texture packs with CITs for enchanted books on newer versions of the game. It is meant as a temporary fix until this functionality comes back to mods such as CIT Resewn or Optifine. The showcase below is using my texture pack <a href="https://www.curseforge.com/minecraft/texture-packs/different-textures-for-enchanted-books">Enchanted Books from Mars</a>. But this mod is compatible with almost all other texture packs adding more enchanted book textures.</p>
<p style="text-align: center;"><img src="https://i.imgur.com/0Muod80.png" width="484"/></p>
<p style="text-align: center;"></p>
<details>
<summary><strong>Configuration</strong></summary>
<p>You can configure this mod directly in-game or edit the JSON file <code>config/cithotfix.json</code> in your profile folder. If you're using Fabric and want to adjust the config values in-game, you'll need to install <a href="https://modrinth.com/mod/modmenu">Mod Menu</a>.</p>
<center>
<p style="text-align: center;"><b>possible_roots</b> - Sets which resource pack paths should be checked by this mod for CITs of enchanted books</p>
